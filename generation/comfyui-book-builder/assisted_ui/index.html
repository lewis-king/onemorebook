REFERENCE PHOTOGRAPHS

Pick one photo or several at once from the file dialog — up to fourteen. Photographs become pages in the order you add them, so start with the beginning of the day (the cake goes last — nobody has cake first). Number each moment with the arrows and click any photo to view it larger while you write its caption. Sharp, realistic photos are best; each one is restyled into the book's illustration style, and you approve every restyle before it is used.

Made for ages 4–7. First, a story for you to read together. Then, the pictures.
